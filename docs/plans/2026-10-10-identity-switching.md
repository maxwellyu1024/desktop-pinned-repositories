# 仓库身份一键切换与闭环

基于 [多代码平台、多账号与仓库身份](2026-10-10-multi-platform-accounts.md#仓库身份) 第 5 步已实现的仓库身份。

## 目标

推荐、匹配、检查、修正形成闭环：

```
① 推荐身份 → ② 自动匹配、补写未设置的值 → ③ 未设置好的仓库
      ↑                                        ↓
⑤ 新仓库、手动改过配置的仓库 ←—— ④ 一键切换 / 套用 / 不使用身份
```

终态指标：

- 切换或套用一个（或一批）仓库的身份：1 次点击，无确认对话框，可撤销。
- 本机现有需要决定的仓库，全部能在列表、管理仓库、提交区一键处理，“未设置好”可降到 0。
- 远程使用了已有身份 SSH 别名的新仓库，不需要任何规则即自动匹配。
- 添加推荐前即可看到每个推荐会补写多少仓库、哪些仓库与之冲突。

## 一键切换

### 身份菜单

所有入口共用一份菜单（`ui/identities/identity-menu.ts`）：

```
✓ 自动（powerpook）        // 当前自动匹配到的身份，未匹配时为“自动（无）”
  ─────────
  powerpook
  forgejo
  …
  ─────────
  不使用身份
  套用 powerpook            // 仅当前身份未设置好时出现
```

- 当前绑定打勾；多仓库时只有共同绑定打勾。
- 选择后立即执行，不弹对话框：
  - 自动 / 指定身份：保存绑定，按新绑定得出身份，写入全部必需改动（作者、签名、SSH 远程改走别名），
    覆盖已有值（属于用户明确选择）；“HTTPS 改用 SSH”属可选改动，不写。
  - 不使用身份：保存绑定，去掉 `ghdock.identity` 标记，不动其他配置。
  - 套用：按当前绑定写入必需改动。
- 写入前记录快照：每个仓库原绑定，以及每个将被改动的键（含 `ghdock.identity`）的原值。
- 完成后显示横幅“已将 jnc 切换为 powerpook。撤销”；有无法改写的远程或写入失败时在横幅中说明数量，
  详情见仓库设置。撤销：恢复原绑定，按快照写回原值（原值不存在则删除键）。
- 仓库设置的 Git 配置页保留逐项预览与勾选，作为需要部分写入时的入口。
- 原“Set Identity…”对话框由菜单取代，删除。

### 入口

| 入口 | 形式 |
| --- | --- |
| 仓库列表右键、工具栏仓库右键 | “身份”子菜单 |
| 管理仓库 | 批量操作中的“身份”菜单按钮，作用于选中仓库 |
| 提交区 | 作者头像旁显示当前身份标签，未设置好时带警告标记；点击弹出同一菜单 |
| 偏好设置身份页 | 每个身份的“N 个未设置好”可点击，打开管理仓库并定位到该身份未设置好的仓库 |

管理仓库的身份分组：每个身份一组；某身份有未设置好的仓库时，紧随其后增加“<身份>，未设置好”分组；
另有“未使用身份”“未设置好”（全部）。

## 按 SSH 别名匹配

- 解析出的远程记录写法中的 SSH 主机（别名）。
- 匹配顺序：远程写法中的 SSH 主机等于某身份的 `sshHostAlias`（不区分大小写）时直接选该身份，
  多个身份同别名取靠前者；否则按规则（主机 + 最长命名空间前缀）。
- 身份可以没有规则（只靠别名匹配）；编辑器与配置文件允许 `rules` 为空。
- 推荐身份的规则仍取组内各顶级命名空间，供未使用别名（HTTPS 或 `git@github.com`）的同组织仓库匹配。

## 推荐时显示后果

对每个勾选的推荐，用已有身份加上勾选的推荐身份匹配所有未使用身份的仓库，按仓库现状归类：

| 类别 | 条件 |
| --- | --- |
| 补写 | 本地作者未设置 |
| 已一致 | 本地作者与身份一致，远程已走别名或不需改写 |
| 冲突 | 本地作者与身份不同，或 SSH 远程未走身份的别名 |

推荐行显示“N 个仓库 · 补写 A 个 · B 个设置不同：仓库名…”，冲突仓库列出名称（最多 3 个，其余计数）。
仓库数按匹配计算，包含只靠规则匹配到的 HTTPS 与 `git@<真实主机>` 仓库，可能多于推荐依据的仓库数。
冲突仓库在添加后显示为未设置好，用一键切换处理。

本机模拟结果（2026-10-10，全部勾选）：

| 推荐 | 仓库 | 补写 | 冲突 |
| --- | --- | --- | --- |
| powerpook | 46 | 28 | jnc、nftbox-web、nftbox-deploy、nftbox-server、trade-evolution |
| forgejo | 12 | 6 | 无 |
| maxwellyu1024 | 8 | 2 | tauri-sqlite-table、openalternative |
| IBAX | 1 | 0 | 无 |
